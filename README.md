# QuickNotes Pad

QuickNotes Pad is a clean, browser-based note-taking application designed to help users quickly capture, categorize, and organize daily thoughts, workplace tasks, and study reminders without requiring an account or setup.

## Features

- **Categorized Notes**: Organize notes into Personal, Work, or Study categories with custom color-coded visual indicators.
- **Client-Side Validation**: Ensures note inputs are non-empty and enforces a maximum limit of 200 characters.
- **Real-Time Search**: Filters displayed notes dynamically as you type based on keyword content.
- **Local Storage Persistence**: Automatically saves all user notes in browser `localStorage` so content survives page refreshes.
- **Responsive Interface**: Stacks inputs cleanly on smaller mobile screens (under 600px width).
- **Clear All Option**: A quick button to reset and wipe all saved notes with a safety confirmation prompt.
